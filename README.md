# Female Welfare Portal
Capstone Project – Web Designing (DCSE0152) | NIET Greater Noida

## Files Included
- `index.html`          → Home page
- `about.html`          → About the portal
- `schemes.html`        → Government schemes table
- `helplines.html`      → Emergency helplines
- `contact.html`        → Inquiry form with basic JS
- `css/style.css`       → Responsive stylesheet

## How to Run
1. Download and extract the folder.
2. Open `index.html` in any modern browser.
3. Navigate using the menu.

## Modules Covered
- Module 1: Website Planning & HTML Development
- Module 2: HTML Components & User Interface
- Module 3: Responsive Design using CSS (style.css)
- Module 4: Basic JavaScript (form alert in contact.html)

Created for educational purposes as part of PBL Capstone Project.
